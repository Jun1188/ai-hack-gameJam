# 카페 대화 모델 설정

메인 메뉴의 **설정 → 대화 모델**에서 API 우선 또는 로컬 모델을 선택한다. API는 Gemini, OpenAI, OpenAI 호환 서버를 지원하며 공급자에 맞는 모델 이름과 API 주소를 입력한 뒤 **모델 설정 적용**을 누른다. 메인 메뉴에서 저장한 선택은 다음 게임 시작부터 사용한다. 기존 명령줄 실행 옵션은 저장한 선택보다 우선한다.

바리스타 전용 씬 `Assets/CafeCoworker/Scenes/CafeBaristaLab.unity`에서는 **Esc → 대화 모델 설정**으로 같은 설정을 연다. 적용 후 창을 닫으면 진행 중인 대화 요청을 취소하고 씬의 공용 추론 실행부를 다시 준비한다. 작업·주문은 설정창을 열기 전 상태로 유지한다. 설정을 열기 전에 일시정지 중이었다면 닫은 뒤에도 일시정지를 유지한다.

공급자·모델·주소·API/로컬 선택은 PC의 PlayerPrefs에 저장한다. 화면에 입력한 API 키는 이번 실행 중에만 메모리에 보관하며 저장 파일·씬·로그에는 기록하지 않는다. 공급자 또는 서버 주소가 바뀌면 이전 공급자·서버의 입력 키를 재사용하지 않는다. 키를 비워 두면 공급자별 환경 변수 또는 기존 Gemini 설정을 사용한다. 포함된 Gemini 키를 OpenAI나 호환 서버로 보내지 않는다.

로컬 모델 선택은 기존에 준비된 로컬 런타임과 모델을 사용한다. 이 변경은 다운로드·패키지 업그레이드·새 빌드를 실행하지 않는다. API 우선 경로의 기존 로컬/자동 답변 대체 동작은 유지한다.

## 이번 검증

- Unity `6000.6.8f1` 통합 코드 컴파일 통과.
- `tools/cafe-model-settings-check.cs`: API/로컬 선택, 공급자별 경로, 저장·복원, 잘못된 주소 거부, 메모리 키의 공급자·서버 분리를 확인했다. 검증 후 기존 선택을 복원했다.
- 메인 메뉴와 바리스타 씬의 실제 Play 설정창을 캡처해 패널·입력 필드·버튼 전체 표시를 확인했다.
- 바리스타 Play에서 설정 열기 → 작업 일시정지 → 검증용 loopback API 설정 적용 → 설정 닫기 → 추론 실행부 재시작과 새 경로 적용 → 이전 입력/일시정지 상태 복원을 확인했다. 검증용 설정은 복원했다.
- 새 공급자의 실제 API 요청, 모델별 응답 품질·지연, OS IME 입력, 다른 PC 및 새 플레이어 빌드는 미검증이다.
