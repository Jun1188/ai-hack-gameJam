# 검증 기록 — 2026-11-05

## 현재: 상호작용 구조 수정과 원인 감사

IMGUI를 UI Toolkit으로 교체하고 TextField/IME, 편집 상태의 그룹화된 스테이지 미리보기, 가감속·회전·WalkRate, R 연속 회전 및 고정 줌을 반영했습니다. 열린 Editor에서 컴파일·UXML/USS 임포트, 한글 문자열 왕복, 미리보기 저장, 기존 규칙과 수동 애니메이션·전체 회전 경계 검사를 수행합니다. 빌드와 Play Mode는 실행하지 않습니다. 이전의 HUD Rect 계산 14조건 검사는 새로운 HUD의 실제 표시 검증으로 간주하지 않습니다. 실제 OS IME 입력과 보행 체감 등 남은 검증은 [원인 점검](root-cause-review.md)을 따릅니다.

마지막 확인 때 사용자가 실행한 Play Mode가 감지되어 상태를 변경하지 않고 읽기만 했습니다. 컴파일 실패·콘솔 오류 0개, 현재 패널의 주요 HUD 경계와 Animator/클립 연결을 확인했습니다. 별도 순수 계산에서 카메라 화면 모서리 864개가 모두 맵 안에 있었습니다. 에이전트가 플레이를 시작하거나 빌드를 생성하지 않았습니다.

## 현재: 색상 연결·HUD·T포즈 수정

- 빌드 및 Play Mode 실행 없이 Editor에서 검증했습니다 (`Logs/presentation-fix.log`).
- `GRAND`의 Color/Normal/Metallic/Roughness를 연결했습니다. 원래 UV를 유지하며, 재생성 시 색상 지정을 무조건 흰색으로 초기화하지 않습니다.
- 규칙 검사 278개 통과. HUD 7개 해상도 × 2개 안전 영역에서 팝업 경계·화면 밖 라벨 제외를 검사했습니다.
- Editor의 수동 PlayableGraph 샘플링으로 Idle → Walk → Idle 전환과 실제 SkinnedMesh 변형을 확인했습니다. Idle 팔 방향은 아래쪽 기준 10.93도(T포즈는 약 90도), Idle/Walk의 최대 메시 정점 차이는 0.2788입니다. 이는 상태 이름만 확인했던 이전 검사와 다릅니다.
- 실제 Game 뷰의 입력·HUD 시각 검증은 사용자가 Play Mode에서 진행합니다.

## 현재: 농장 복구 흐름 변경

- **새 빌드와 Play Mode 실행은 수행하지 않았습니다.** 플레이 검증은 사용자가 담당합니다.
- Unity Editor에서 C# 컴파일, 씬·카탈로그 갱신 및 규칙/참조 검사 **278개 통과**.
- 무너진 목재 20개 정리 전 분류/재건 차단, 분류의 종류·개수·층·방향 판정, 동일 재료의 재건 재사용, 정리/분류 완료 기록 유지와 최종 완성을 검증했습니다.
- `Logs/farm-repair-editor.log`에 `PROTOTYPE_CHECKS_OK: 278`와 `PROTOTYPE_GENERATED`가 기록되어 있습니다.
- 기존 Windows 실행 파일과 캡처는 갱신하지 않았으며 아래는 변경 전의 이력입니다.

## 이전 버전 이력 — 현재 농장 복구의 Play 검증 결과가 아님

환경: Windows, Unity 6000.6.8f1, Unity CLI 1.0.0-beta.16. CLI 업데이트 조회는 CDN DNS 오류로 실패했으며 설치된 버전을 사용했습니다. 처음 샌드박스 안에서는 라이선스 IPC 초기화가 실패해 승인된 실행 경로에서 빌드를 수행했습니다.

- Editor 규칙/데이터/에셋 참조 검사 **136개 통과**. 곳간 10단계·26부품, 초기 기초 4개, 무거운 블록 집기 금지, 선행 조건·방향·윗틀 맞춤과 완성을 검증합니다.
- Python 중계 검사 **16개 통과**. 오류 JSON/행동/ID, 모호한 문장, 중복 요청, CLI 실패·시간 초과, 공개 상태 필터링, 밀기·맞추기·일괄 명령을 검증합니다.
- Windows 실행 파일 자체 검사 **851개 통과**. 실제 Codex HTTP 요청, WASD 및 채팅 중 이동 차단, Idle/Walk, 지팡이 세로 방향, 네 화면 비율·회전 각도·줌 양 끝의 맵 내부 경계, 스테이지 전환·취소·초기화, 우물과 곳간 완주를 검증합니다.
- 실제 Codex가 `B1을 N1에 놓아`를 pick_up/place로, `K5를 N5로 밀어`를 push로 반환했습니다. 정답·회상은 요청 snapshot에서 제외합니다.
- 할아버지: 유효한 Humanoid avatar, 스킨 본 21개, Unity 임포트 UV 29,550개. Idle 8.333초/Walk 4.625초 루프를 입력 트리거로 전환합니다. 원본 grand_9.fbx에는 애니메이션·재질·텍스처 데이터가 없으며 별도로 받은 애니메이션과 지팡이 자료를 사용합니다.
- 별도 렌더 타깃의 우물 시작/완성, 곳간 시작/완성, 할아버지 근접 이미지를 확인했습니다. 테스트 창을 숨겨 실행하므로 이미지는 3D 월드만 포함합니다. HUD의 최종 화면 배치는 별도 시각 검증 범위로 남습니다.

빌드 및 실행 기록은 무시된 `ai-hack-test/Logs/prototype-build.log`, `ai-hack-test/Builds/Windows/player-selftest.log`, `selftest.json`에 있습니다. Unity 라이선스 부가 entitlement 조회 및 개발용 종료 시 메모리 진단 메시지가 있으나 빌드와 플레이어 검사는 성공했습니다.
