## P0 — 사용자가 진행할 루프/청음 확인

후속 반영: MainMenu의 `MainMenuController` Inspector에도 같은 **API 키 직접 입력**을 제공한다. MainMenu에서 설정한 키는 CafeGame의 `LocalCafeModel`이 그대로 읽는다. 키 설정은 로컬 Resources 파일을 사용하며 MainMenu에서 추론 모델은 부팅하지 않는다.

초기에는 Play를 실행하지 않았다. 이후 사용자가 허용한 범위에서 대화/입력 프레임·첫 글자의 실제 화면과 시작 연출·노을·차량 이동을 확인했다. 전체 영업/관계 루프와 새 빌드는 실행하지 않았다. API 정상 여부는 사용자가 확인했다.
