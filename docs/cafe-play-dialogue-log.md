# 2026-11-06 Play Mode 실험 대화

Unity 6000.6.8f1, `Assets/Scenes/test-loop-merge02.unity`에서 CLI로 실행했다. 아래 입력은 에이전트가 작성한 합성 시험 문장이다. 사용자의 실제 대화나 인증 정보는 포함하지 않는다. 도구가 반환한 답변을 수정하지 않고 옮겼다. 외부 API 성공을 확인한 기록은 아니며, `모의 API`는 루프백 서버가 반환한 고정 시험 문장이다.

## 최종 코드로 실행한 대화

손님은 `cus_jeju`였다. 첫 입력은 UI Toolkit TextField의 값 설정과 Return KeyDown 이벤트로 전송했다. 나머지는 `CafeSession.SendChat`을 호출했다. OS IME 조합이나 실제 키보드 타이핑을 검증한 것은 아니다.

| 입력 | 실제 답변 | 소스 | 소요 시간 |
|---|---|---|---|
| 오늘 바다는 어땠어요? | 아까 이야기하던 일을 떠올리니 마음이 한결 편안해지네요. | 모의 API | 0.014초 |
| 바다에 관해 어떤 점이 좋으세요? | 바다는 제주에서 가장 큰 자랑이야. 바다 건너 손주가 보는 귤밭 사진에 빨리 끝나면 좋겠수다. 바다 속 물이 흐르는 소리만 들어도 마음이 편해지지. | API 연결 실패 후 실제 로컬 LLM | 55.396초 |
| 더 자세히 들려주세요 | 아까 고른 음료는 언제 나오나요? 기다림이 꽤 길어졌수다. 기다린 시간도 생각해 주시면 좋겠어요. | 양쪽 연결 실패 후 DB 최고 유사도 매크로 | 4.114초 |
| 안녕하세요 | 안녕하우꽈? | 양쪽 연결 실패 후 후보 생성·필터·순위 선택 | 4.085초 |

로컬 응답의 두 번째 문장은 의미가 어색하고, 전체 말투도 일관적이지 않다. 연결 경로의 성공을 답변 품질의 성공으로 판단하지 않았다. 매크로/어휘 분기를 강제하기 위해 이 실행에서만 임계값 0/1을 사용했다. 저장된 기본값은 0.60이다. 로컬 응답 시간은 API 연결 실패와 모델 부팅을 포함하며, 모의 API 시간은 실제 서비스 속도의 근거가 아니다.

## 앞선 실행의 대화

아래는 후보 생성·필터·순위 선택 알고리즘을 추가하기 전, 같은 작업 중 진행한 첫 Play 실행이다. 최종 알고리즘의 효과를 입증하는 근거로 사용하지 않는다. 손님은 `cus_trainer`였다.

| 입력 | 실제 답변 | 소스 | 소요 시간 |
|---|---|---|---|
| 오늘 운동은 어떠셨어요? | 아, 그렇군요! 어느 이야기인지 다시 알려 주실래요? | 모델 경로 실패 후 기존 어휘 조합 | 33.013초 |
| 오늘 운동하고 나니 기분은 어떠세요? | 기분은 최고야! 오늘 운동량도 적당했고, 쉬는 시간도 잘 썼어. | 실제 로컬 LLM | 19.819초 |
| そうですか、ではなく、そうなんですね。運動のお話を続けてください。 | 아까 이야기하던 일을 떠올리니 마음이 한결 편안해지네요. | 모의 API | 0.010초 |

## 취소 검사

`취소 검사 입력입니다` 전송 직후 요청 중단, `손님 전환 검사 입력입니다` 전송 직후 다른 손님 선택, `서빙 취소 검사 입력입니다` 전송 직후 음료 제공을 실행했다. 세 요청 모두 답변이 추가되지 않았다. 지연 확인 뒤 이전 손님의 답변 수는 4개로 유지됐다.
