# 곳간 조립 프로토타입

## 농장 스테이지의 전체 목표

현재 목표는 **무너진 건물 정리 → 방해 오브젝트를 알맞은 노드 위치·형태에 배치 → 곳간 재건**입니다. 아래 엑셀 10단계는 마지막 재건 단계의 세부 상태머신입니다.

1. **잔해 정리:** 목재 부품 20개가 건물 터에 쓰러진 채 시작해 이동을 막습니다. 로봇에게 부탁해 임시 정리장 `C1`~`C5`로 옮기세요. 모든 목재가 정리장에 내려놓여야 분류 단계가 열립니다. 기초 블록 복구와 재건 노드는 이때 잠겨 있습니다.
2. **위치·형태 맞추기:** 회상(Q)으로 `SORT1`~`SORT7`의 종류·개수·방향·쌓는 순서를 보고 배치하세요. 잘못 배치해도 옮겨 고칠 수 있습니다. 위에 재료가 있으면 먼저 위의 재료를 빼야 하며, `C5` 등을 작업 버퍼로 쓸 수 있습니다.
3. **곳간 재건:** 분류 목표 20개를 모두 만족하면 기존 10단계가 열립니다. 분류했던 부품을 다시 집어 조립에 사용합니다. 재료는 새로 생성되지 않으며, 정리·분류 완료 기록은 재건 도중 유지됩니다. 초기화하면 처음의 무너진 상태로 돌아갑니다.

예: `LW1을 C1에 놓아` → 정리 완료 후 `J1을 SORT1에 놓아` → 분류 완료 후 `FR1을 N7에 놓아`. 각 단계에서 사용 가능한 노드만 화면과 LLM 공개 상태에 나타납니다. Q 회상은 현재 단계에 필요한 배치만 보여 줍니다.

보관 노드에서는 큰 벽·지붕 부품을 축소·눕힘 표현으로 쌓고, 재건 시 원래 조립 크기와 자세로 복원합니다. 부품 ID와 논리 상태는 동일하게 유지합니다. 농작물 밭·흙길·울타리로 농장 공간을 구성합니다.

## 재건의 세부 순서

원본 자료는 `Assets/docs/reference/곳간_조립순서.xlsx`와 `puzzle_house_0.png`입니다. 엑셀은 수정하지 않았습니다. 10단계·26부품과 선행 조건을 `Assets/Data/house_01.json`으로 옮겼으며, 벽은 개별 못/샛기둥 작업 대신 프레임 패널로 묶습니다. 형태는 이미지처럼 주춧돌 위의 바닥 틀·장선·바닥판·벽 프레임·윗틀·삼각 서까래·지붕판으로 구성합니다.

| 단계 | 상태 조건 |
|---|---|
| 1. 기초 6개 | 처음부터 4개는 배치되어 있고 K5/K6을 밀어 복구 |
| 2. 바닥 틀 1개 | 기초 6곳 완성 |
| 3. 장선 4개 | 바닥 틀 완성 |
| 4. 바닥판 1개 | 장선 4개 완성 |
| 5. 긴 벽 2개 | 바닥판 → 뒤 벽 → 창문 벽, 방향 판정 |
| 6. 짧은 벽 2개 | 긴 벽 → 옆 벽 → 문 벽, 방향 판정 |
| 7. 윗틀 2개 | 벽 4개 완성, 배치 후 모서리 맞추기 |
| 8. 서까래 5쌍 | 윗틀 완성 → 양 끝 → 안쪽 → 가운데 |
| 9. 지붕판 2개 | 서까래 5쌍 완성 |
| 10. 문짝 1개 | 벽 4개 완성 |

문짝은 엑셀의 명시적 선행 조건에 따라 벽 4장이 완성되면 지붕보다 먼저 달아도 됩니다. 지붕 완성을 문짝의 추가 조건으로 강제하지 않습니다. 윗틀의 `adjust`는 모서리가 맞물린 상태를 논리적으로 확정하며, 무너짐 물리 대신 경고와 복구 가능한 명령을 사용합니다.

HUD에서 곳간/우물을 선택할 수 있습니다. 동일 인게임 씬의 스테이지 루트만 재구성합니다. Q 회상은 곳간의 현재 미완성 단계만 보여줍니다. E로 부탁하고 ID는 화면에 표시된 값을 사용합니다.

- 기초: `K5를 N5로 밀어` (`push`). 기초는 들 수 없습니다.
- 배치: `FR1을 N7에 놓아` (`pick_up`, `place`).
- 방향: `LW2를 180도로 돌려` (`rotate`, 절대 방향).
- 맞춤: `U1을 N17에 맞춰` (`adjust`, 먼저 해당 노드에 배치).
- 일괄 배치: `J1을 N8에, J2를 N9에, J3을 N10에, J4를 N11에 놓아`.

후보를 하나로 특정할 수 없으면 되묻습니다. 정답/선행 조건/회상은 모델 요청에 포함하지 않고 Unity가 검사합니다. 단계 간 의존성은 JSON 조건으로 정의하고, 선행 부품을 빼는 것도 차단합니다. 프레임과 지붕의 구조적 접합부는 지정된 조립 노드에서 겹침을 허용하며, 재료 보관 위치에서는 일반 겹침 검사를 유지합니다.

부품은 보관 중에는 축소된 모형으로 표시하고 설치 시 실제 조립 크기로 복원합니다. 이는 큰 바닥 틀·벽 패널을 한정된 화면 안에서 식별하기 위한 프로토타입 표현입니다. 로봇은 구조물 외곽에서 조립할 수 있게 노드별 상호작용 거리를 사용합니다.

`cane_grand.fbx`는 지팡이 단독 메시이며, 함께 제공된 Color/Normal 텍스처를 기본 URP/Lit에 연결해 오른손을 따라가게 합니다. 일반 Mixamo 클립에는 지팡이용 손잡이 자세가 없으므로 세로 방향과 바닥까지의 길이를 보정하며, 전용 지팡이 보행/손 IK는 포함하지 않습니다. 할아버지 본체는 추가 제공된 `GRAND`의 동일 모델 식별자 `.fbm` 폴더에서 Color/Normal을 연결하고, metallic과 roughness를 URP의 metallic(R)/smoothness(A=1-roughness) 형식으로 패킹합니다. FBX의 원래 UV는 변경하지 않습니다.
