# ai-hack-gameJam



## 원론적인 PR의 작업 흐름은 Feature / hotfix -> develop -> Master 입니다.  

### Master Branch는 안정적으로 돌아가는 버전만을 다루는 안정화 브랜치입니다.  

그 이외의 Branch는 기여자가 완료한 작업과 compare --> conflict를 해결한 뒤 Merge합니다.  

---------------------

### dev/ 브랜치 단위로 게임, 프로토타입, 프로젝트를 나눠주세요.  
작업유형-dev/, dev-작업/ 형태로 작명하기를 권장합니다.  


> proto-dev/는 특별히 프로토타이핑 프로젝트에 사용합니다  
> / 이하에 프로토타입 프로젝트 네임을 적으세요  

-----------------  


### Feature Branch는 dev/에서 분기하여 개발하고자 하는 기능을 개발합니다.   
Branch 작명은 Feature-작업 혹은 Feature/작업로 권장합니다.   

-----------------  

### hotfix Branch는 dev에서 발생한 버그를 해결하기 위해 분기합니다.  
Branch 작명은 hotfix-작업 혹은 hotfix/작업으로 권장합니다.
