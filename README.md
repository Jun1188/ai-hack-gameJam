# ai-hack-gameJam

## 2026.11월 5~6 게임인재원 AI 해커톤(게임잼) 단기 협업을 위한 저장소다.  



## 원론적인 PR의 작업 흐름은 main -> dev/ -> 하위 브랜치 (ex. feature/)  



#### main 브랜치를 안정화 버전으로 한다.  

#### dev/ 브랜치는 프로토타입, 불안정화, 신기능 구현 중인 버전이다.  

##### 그외 브랜치도 dev/에 준하며, 브렌치 이름에 브랜치 분기  의도를 적었다.

##### 특히 feature/은 미세 기능 구현, codex/는 ai 주도 개발 브랜치다.
